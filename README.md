# Projeto Development Front-End

## Sobre o Projeto
Aplicação Front-End desenvolvida utilizando HTML, CSS e JavaScript, consumindo a API Rick and Morty para exibir personagens de forma dinâmica e interativa.

## Funcionalidades
- Listagem de personagens
- Busca por nome
- Filtros
- Paginação
- Modal de detalhes
- Interface responsiva

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Rick and Morty API
